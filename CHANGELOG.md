# Changelog

This project does not generate a changelog from commit messages. Each release is
curated by hand, and the exact release notes are in `docs/releases/`.

## [0.1.0-alpha.1] - 2026-10-31

The first source-only CLI developer preview. It is unaudited, holds no funds, and
does not promise a stable data format. See
[`docs/releases/v0.1.0-alpha.1.md`](docs/releases/v0.1.0-alpha.1.md) for the
supported surface, recovery artifact, network evidence, and known limitations.
