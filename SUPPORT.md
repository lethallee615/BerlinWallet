# Support

Berlin Wallet is an **unaudited developer preview**. There is no production
support, no service-level agreement, and no bug bounty.

## Where to ask

- **Questions and testing discussion:** GitHub Discussions.
- **Actionable bug or feature:** GitHub Issue using the templates.
- **Security vulnerability:** private reporting through
  [SECURITY.md](SECURITY.md); do not open a public issue.

## What to include

- release tag or commit;
- OS and architecture;
- network and chain backend;
- exact command and the smallest reproduction;
- expected vs. actual behavior;
- redacted logs, txid, and block height where relevant.

Never include a mnemonic, passphrase, invite code, RPC credential, live data
directory, or unredacted backup.

## What is not supported

- mainnet (disabled in the alpha);
- real funds or production custody;
- GUI, mobile, or exchange integration;
- federation solvency or guardian operations;
- third-party Esplora/Electrum/Fedimint/Bitcoin Core services.

## Response expectations

This is a volunteer project. Reports are triaged into the issue queue on a
best-effort basis. P0 reports (funds at risk or primary flow broken) take
priority. There is no guarantee of a response or fix date.
